# plato-config

> Configuration management for PLATO rooms and services

## What This Does

plato-config provides Python configuration management for PLATO. It handles loading, validating, and accessing configuration values for rooms, sensors, and the broader PLATO pipeline.

## Install

```bash
pip install plato-config
```

## Modules

### `config.py` — Configuration Loader
Loads and validates PLATO configuration from files or dictionaries.

## Testing

23 tests covering configuration loading, validation, defaults, and access patterns.
